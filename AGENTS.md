# Agent Instructions

All agents must use the repository `venv/` virtual environment for every Python
dependency install and for running Python tooling. Do not install dependencies
globally or into other environments (for example `.venv/`). If the `venv/`
directory is missing, create it with `python -m venv venv` and then use
`venv\\Scripts\\python.exe` and `venv\\Scripts\\pip.exe` for all commands.
